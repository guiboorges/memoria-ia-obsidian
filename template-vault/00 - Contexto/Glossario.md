# Glossário — Lumen

> Os termos do projeto, com o significado **aqui**. Evita que o Claude (ou alguém novo) use palavras diferentes para a mesma coisa.

| Termo | Significado no Lumen |
|---|---|
| **Turma** | Um horário fixo que se repete (ex.: Yoga, terças às 19h). |
| **Aula** | Uma ocorrência concreta de uma turma (ex.: Yoga de 14 de outubro). |
| **Reserva** | Um lugar de um aluno numa aula. |
| **Pacote** | Conjunto de aulas pré-pagas (ex.: 10 aulas, válido por 3 meses). |
| **Lista de espera** | Fila de alunos para uma aula cheia; o primeiro entra se alguém cancelar. |
| **Piloto** | Os 3 estúdios que testam o Lumen antes do lançamento. |
