# Glossary — Lumen

> The project's terms, with what they mean **here**. Keeps Claude (or anyone new) from using different words for the same thing.

| Term | Meaning in Lumen |
|---|---|
| **Class** | A fixed, recurring time slot (e.g. Yoga, Tuesdays at 7 pm). |
| **Session** | One specific occurrence of a class (e.g. the October 14 Yoga). |
| **Booking** | A student's spot in a session. |
| **Pack** | A set of prepaid sessions (e.g. 10 sessions, valid for 3 months). |
| **Waitlist** | A queue of students for a full session; the first one gets in if someone cancels. |
| **Pilot** | The 3 studios testing Lumen before launch. |
